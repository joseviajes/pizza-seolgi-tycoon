# 피자설기 타이쿤: 나도 어린이 CEO! (Pizza Seolgi Tycoon)

> **유행하는 상품을 판매하면 무조건 돈을 벌 수 있을까?**

초등학교 4~6학년을 위한 창업 교육용 인터랙티브 웹 시뮬레이션입니다.
「검색 데이터로 발견하는 나만의 창업 아이디어」 90분 체험특강에서 사용하도록 만들었습니다.
학생들은 가상의 피자설기 가게를 운영하면서 **손님 수, 경쟁 가게 수, 판매 가격, 재료비, 고정비**에 따라
매출과 이익이 어떻게 달라지는지 직접 확인합니다.

## 1. 프로그램 소개

| 기능 | 설명 |
|---|---|
| 우리 동네 거리 | 클레이 질감의 SVG 가게·손님이 설정에 따라 실제로 늘고 줄어듭니다. 손님 그림 1개 = 10명, 나의 가게는 로열블루, 경쟁 가게는 라벤더색입니다. |
| 운영 조건 조작 | 기본 모드(손님 수, 가게 수)와 펼치기 버튼으로 여는 심화 모드(판매 가격, 재료비, 고정비)가 있습니다. 슬라이더, ＋/－ 버튼, 키보드 화살표로 조작합니다. |
| 경영 결과 | 평균 손님 수, 매출, 재료비, 고정비, 전체 비용, **하루 이익(가장 크게 표시)**, 손익분기점, 상태에 따라 표정이 바뀌는 CEO 캐릭터를 보여 줍니다. |

### 기술 특징
- **`index.html` 파일 하나**로 동작합니다. CSS, JavaScript, SVG 그림이 모두 이 파일 안에 들어 있습니다.
- 외부 라이브러리, CDN, 서버, 데이터베이스, API 키를 쓰지 않습니다. **인터넷이 없어도 실행됩니다.**
- 회원가입, 로그인, 개인정보 수집, 외부 전송, 광고, 결제 기능이 없습니다. 기록은 화면 메모리에만 있고, 새로고침하면 사라집니다.
- 반응형(PC·태블릿·모바일), 키보드 조작, 화면 낭독기 지원(레이블, `aria-valuetext`, 실시간 알림), 모션 감소 설정을 지원합니다.
- 서체: 카페24 써라운드(제목)와 나눔스퀘어라운드(본문)가 **컴퓨터에 설치되어 있으면** 그 서체를 쓰고, 없으면 Apple SD Gothic Neo, 맑은 고딕, Noto Sans KR 등 기본 서체로 자연스럽게 바뀌어 표시됩니다.

## 2. 로컬 실행 방법

1. 이 폴더에서 `index.html`을 찾습니다.
2. 파일을 더블클릭하거나 Chrome, Edge, Safari, Whale 등의 브라우저 창으로 끌어다 놓으면 바로 실행됩니다.

(선택) 로컬 웹 서버로 실행하려면 아래 명령을 씁니다.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000` 을 엽니다.

> 클립보드 자동 복사는 브라우저 보안 정책에 따라 `file://`로 열었을 때 막힐 수 있습니다. 이때는 글상자의 글이 자동으로 선택되므로 Ctrl+C(휴대폰은 길게 누르기)로 복사하면 됩니다. 배포한 주소(https)에서는 자동 복사가 정상적으로 동작합니다.

```bash

```

```bash

```


- 가게가 늘어난다고 **항상** 이익이 줄어드는 것은 아닙니다. 손님이 함께 늘거나(이벤트 3) 가게마다 경쟁력이 다를 수 있다는 점을 꼭 짚어 주세요.

## 6. 계산 공식과 가정

**가정:** 모든 가게의 인기가 같고, 손님 1명이 상품 1개를 산다고 봅니다. 가게 수에는 우리 가게도 포함됩니다.

```
가게당 평균 손님 수 = 전체 손님 수 ÷ 전체 가게 수
하루 매출          = 가게당 평균 손님 수 × 판매 가격
하루 재료비        = 가게당 평균 손님 수 × 개당 재료비
하루 전체 비용      = 하루 재료비 + 하루 고정비
하루 이익          = 하루 매출 − 하루 전체 비용
손익분기점 손님 수   = ⌈ 하루 고정비 ÷ (판매 가격 − 개당 재료비) ⌉   (올림)
```

- 계산하는 중간에는 반올림하지 않고, 화면에 원 단위로 보여 줄 때만 반올림합니다. 평균 손님 수는 소수점 한 자리까지 보여 주고, 실제 사람이 나뉘는 것이 아니라 평균값이라는 안내 문구가 함께 나옵니다.
  (항목마다 따로 반올림하므로 가게 수가 7개나 9개일 때 화면에 보이는 매출 − 비용과 이익이 1원 다를 수 있습니다.)
- 상태 판정: 반올림한 이익이 0보다 크면 **이익 발생**, 0이면 **손익분기점**, 0보다 작으면 **손해 발생**입니다.
- 손익분기점 예외 처리 (무한대, NaN 같은 값은 표시되지 않습니다):
  - 판매 가격 = 재료비, 고정비 0원 → “판매에 따른 이익이 발생하지 않아요”
  - 판매 가격 = 재료비, 고정비 > 0원 → “손익분기점이 없어요” (아무리 팔아도 고정비를 채울 수 없음)
  - 판매 가격 < 재료비 → “많이 팔수록 손해가 커져서 손익분기점이 없어요”
  - 고정비 0원이고 판매 가격 > 재료비 → 손익분기점 0명 (1개만 팔아도 이익)

**입력 범위**

| 항목 | 최소 | 최대 | 단위 | 기본값 |
|---|---|---|---|---|
| 하루 손님 수 | 10명 | 300명 | 10명 | 100명 |
| 전체 가게 수 | 1개 | 10개 | 1개 | 1개 |
| 판매 가격 | 2,000원 | 5,000원 | 500원 | 3,000원 |
| 개당 재료비 | 500원 | 3,000원 | 500원 | 1,500원 |
| 하루 고정비 | 0원 | 100,000원 | 5,000원 | 30,000원 |

**이벤트 효과**: ① 가게 5개·손님 100명 ② 가게 10개·손님 100명 ③ 손님이 200명보다 적으면 200명, 200명 이상이면 300명 ④ 손님 약 50% 감소(10명 단위로 반올림, 최소 10명) ⑤ 재료비 +500원(최대 3,000원) ⑥ 손님 +50명(최대 300명). 범위 끝에 닿으면 이벤트 카드에 안내 문구가 나옵니다.

**추가 검증 (모두 통과)**
- 평균 33.3명(손님 100명, 가게 3개)의 소수점 표시와 안내 문구, 이익 20,000원
- 입력 최솟값/최댓값 제한, 범위 밖 값 보정, 끝에서 ＋/－ 버튼 비활성화, 키보드 화살표 조작
- 가게 오브젝트 수(1·5·10개), 손님 그림 수(100명 → 10개, 300명 → 30개)
- 이벤트 6종의 효과와 최솟값/최댓값 처리 안내, ‘교육용 가상 상황’ 표시
- 미션 1~5 초기 조건과 결과, 예상 결과 공개 전 숨김, 예상 맞힘 피드백, 축하 대화상자, 미션 5 성공 판정(이익 > 0)과 성공 메시지, 배지 개수
- 실험 기록: 5개 제한, 하나 지우기, 모두 지우기
- 클립보드 복사 내용이 요구 형식과 정확히 일치하는지, 클립보드를 쓸 수 없을 때 대체 동작(글상자 선택과 안내)
- 그래프 A 막대를 눌러 가게 수 변경
- 외부 링크 6개 모두 `target="_blank"`와 `rel="noopener noreferrer"` 적용
- 처음부터 다시 하기(확인 대화상자), 게임 방법 대화상자
- 모바일(375px), 태블릿(820px)에서 가로 스크롤 없음 (가게 1/5/10개, 기록과 미션 화면 포함)
- 모션 감소 설정에서 등장 애니메이션 꺼짐
- 브라우저 콘솔 오류와 경고 0건

## 9. 학습용 주의사항
- 이 프로그램은 창업과 시장 경쟁을 이해하기 위한 교육용 가상 시뮬레이션입니다.
- 모든 가게의 인기가 같고, 손님 1명이 상품을 1개씩 구매한다고 가정합니다.
- 실제 피자설기 시장의 손님 수, 상품 가격, 매출, 수익을 나타내는 자료가 아닙니다.
- 실제 창업에서는 상품의 품질, 위치, 경쟁력, 소비자 수요, 가격에 따른 구매 행동, 인건비, 세금 등 다양한 요소를 추가로 고려해야 합니다.
